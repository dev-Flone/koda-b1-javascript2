# Program menhitung Luas dan Keliling Lingkaran

## Cara kerja
1. Membuat object lingkaran dengan properti jari-jari dan method.
2. method luas() untuk menghitung luas dari lingkaran dengan rumus phi x r x r.
3. method keliling() untuk menghitung keliling dari lingkarang dengan rumus 2 x phi x r.
4. Hasil kedua method ditampilkan menggunakan console.log(lingkaran.luas()) dan console.log(lingkaran.keliling()).
